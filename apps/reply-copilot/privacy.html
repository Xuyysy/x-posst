REPLY COPILOT · 本地测试版

隐私说明

版本 0.1.0-beta · 本地测试版说明，尚未通过 Chrome Web Store 审核。

发送给 AI 服务的信息

为了生成回复，扩展会将你主动选择的 X 帖子文字、帖子链接、个人风格配置、你主动添加的写作样本，以及最多 20 条已选择的历史回复发送到你配置的 AI 服务（当前为 DeepSeek 的 api.deepseek.com）。请在使用前阅读服务提供方的隐私条款。

本地保存的信息

DeepSeek API Key、个人风格、写作样本、已选择的回复、反馈和使用统计保存在当前浏览器的扩展本地存储中，不会发送到 Reply Copilot 自有服务器。API Key 不会暴露给 X 页面脚本。本地浏览器存储不等于服务器端密钥保护；能够访问此浏览器配置文件的人员或软件可能读取扩展数据。

不会收集的信息

扩展不会收集 X 密码或 Cookie、浏览历史、无关时间线内容、私信或账号凭据，也不包含第三方分析、广告 SDK 或隐藏遥测。

历史与发送状态

新建的历史记录不会保存完整原帖正文。复制或填入草稿不会被认定为已发布；扩展不会自动点击 Post，也无法验证回复是否发布。

如何清除

你可以在设置中心修改或清除 API Key、编辑或重置个人风格、删除单条写作样本、清空历史和使用数据。卸载扩展后，Chrome 会按扩展存储行为移除其本地数据。

发布前说明

这是本地测试版的隐私说明草稿。正式分发前，发布者仍需核实实际数据流、数据保留方式、服务提供方条款、法律义务、联系信息及 Chrome Web Store 披露要求。当前版本不代表已通过商店审核。
